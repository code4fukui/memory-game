# memory-game

2の累乗が並ぶグリッドからセルを選択し、数値を2進数で表現する、シンプルでやりごたえのある記憶ゲームです。

## デモ

ブラウザ上で実際にプレイできます: **[https://code4fukui.github.io/memory-game/](https://code4fukui.github.io/memory-game/)**

## 遊び方

1.  画面上部に目標となる数値が表示されます（例: 「13をおぼえてね」）。
2.  4x4のグリッドのセルをクリックし、選択したセルの値の合計が目標の数値になるようにします。
3.  グリッドの各セルは2の累乗（1, 2, 4, 8, ... 32768）を表しています。
4.  選択したセルの合計が正解すると、自動的に次のレベルに進みます。
5.  全10レベルをクリアするとゲームクリアです。進むにつれて目標の数値は大きくなります。

## 特徴

- **2進数パズル:** 数値を2の累乗の和として表現することで、記憶力に挑戦します。
- **段階的な難易度:** 全10レベルで構成され、目標の数値は最大65,535まで大きくなります。
- **インタラクティブなグリッド:** 選択したセルが視覚的にわかりやすい4x4のグリッド。
- **軽量かつ高速:** サーバーサイドの依存関係がなく、すべてブラウザ上で動作します。

## 使い方

ローカルでゲームを実行するには、`index.html`ファイルをWebブラウザで開くだけです。
